**English:** [Full documentation](README.en.md) · [Changelog](CHANGELOG.en.md)

**v1.6.1-preview** · Three independent, read-only skills for evidence-based pre-implementation challenge:

- [task-grill](skills/task-grill/SKILL.md) for ChatGPT
- [codex-task-grill](skills/codex-task-grill/SKILL.md) for Codex
- [antigravity-task-grill](skills/antigravity-task-grill/SKILL.md) for Google Antigravity (App / IDE / CLI)

**Статус / Status:** structural checks passed; 57 behavioral scenarios are documented but **live-model regression tests have not run**. This is a public preview, **not** a stable release.

**Что делает / What it does:** verifies real evidence, preserves owner-approved decisions, avoids redundant questions, challenges consequential risks, and prepares bounded handoffs without launching agents or changing repositories without explicit authorization.
