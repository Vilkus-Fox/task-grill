# Task Grill 1.6.1 Preview · Прожарка задачи

[English](README.en.md) · [История изменений](CHANGELOG.ru.md) · [Наверх](README.md)

## Для чего это

**Task Grill** помогает владельцу приложения, сайта или игры разобраться в существенных требованиях **до реализации**. Он анализирует доступные доказательства, предлагает конкретные варианты, проверяет инженерные риски и подготавливает ограниченную, проверяемую передачу задачи исполнителю. Цель не в количестве вопросов, а в уменьшении переделок.

Это **аналитический Skill**, а не автономный разработчик. Он не даёт разрешений на изменение репозитория, запуск агентов, слияние PR или публикацию проекта.

## Две версии

| Навык | Где применять | Назначение |
| --- | --- | --- |
| [task-grill](skills/task-grill/SKILL.md) | ChatGPT | Цели продукта, UX, требования, решения владельца, риски, handoff |
| [codex-task-grill](skills/codex-task-grill/SKILL.md) | Codex | Анализ существующего кода и тестов, архитектурные риски, проверка готовности задачи |

Оба Skill могут работать независимо. При совместной работе они передают **только существенные изменения**, а не повторяют интервью. Общие справочники находятся в [shared/references](shared/references), а внутри каждого Skill есть автономная копия.

## Как пользоваться

1. Установите нужный Skill в своей среде. В ChatGPT откройте библиотеку Skills (`/skills`) и импортируйте ZIP, содержащий **только один** Skill. Для Codex разместите каталог Skill согласно инструкции вашей установленной среды. Не смешивайте два Skill в одном импортируемом ZIP.
2. Сообщите задачу обычным языком, например: «Прожарь редизайн главной страницы; сначала найди реальные ограничения в репозитории. Пока ничего не меняй».
3. Если важны конкретный исполнитель, независимая оценка другого ИИ или визуальное согласование, укажите это. Skill должен восстановить ранее согласованные решения и уточнять лишь действительно существенное.
4. Получите вывод: **цель, подтверждённые факты, открытые решения, риски, условия приёмки, ограниченные этапы и следующий разрешённый шаг**.
5. Реализацию, создание Issue/PR или публикацию разрешайте **отдельно**, вне аналитического режима.

Если источники недоступны, Skill обязан различать подтверждённые факты и непроверенные предположения. Отсутствие доступа у второго агента не отменяет ранее проверенный факт: сохраняются источник, SHA и статус повторной проверки.

## Режимы принятия решений

- **QUICK:** маленькая понятная ошибка. Полная прожарка обычно не нужна.
- **DESIGN:** обсуждение вариантов, UX, архитектурных и продуктовых решений.
- **HANDOFF:** требования с критериями приёмки и целевым исполнителем, либо явно обозначенная нейтральная передача.

Это удобные описания глубины работы, **не отдельные переключатели программного интерфейса**. Никакое количество дополнительных Skills не обязательно: **ноль** вполне допустимо.

## Самостоятельное испытание внешнего агента

Если владелец хочет проверить, на что способен, например, Antigravity, первый промт содержит цели, ограничения и критерии приёмки, **но не готовую карту файлов и решения другого эксперта**. Для значимого визуального редизайна сперва согласуют наглядный прототип. Затем исполнитель получает отдельное разрешение на код.

## Проверка качества

В [SCENARIO_TESTS.md](shared/references/SCENARIO_TESTS.md) описаны **57 сценариев ожидаемого поведения**; порядок оценки в [EVALUATION_GUIDE.md](tests/EVALUATION_GUIDE.md).

- **PASS:** структурная валидация и проверка целостности двух автономных сборок.
- **NOT RUN:** систематические поведенческие испытания на моделях и сравнение с исходным Grill Me.
- **Важно:** сценарии, записанные текстом, не являются 57 успешно выполненными тестами.

Команды из корня репозитория:

```sh
python tests/STATIC_VALIDATION.py
python tests/HANDOFF_STRUCTURE_TEST.py
python scripts/sync_shared.py
```

Последняя команда обновляет копии общих reference-файлов внутри двух Skill; используйте её **только при намеренном редактировании источников**.

## Сборка ZIP

Для ChatGPT упакуйте **только** папку `skills/task-grill` так, чтобы внутри ZIP был каталог `task-grill/SKILL.md`. Для Codex аналогично `skills/codex-task-grill`. При наличии официального упаковщика среды предпочтителен он. Проверяйте `SKILL.md`, `agents/openai.yaml` и каталог `references/` перед импортом.
